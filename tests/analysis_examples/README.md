# Analysis examples

Numbered scripts included in `docs/api/analysis.md` and run once by
`pytest tests/test_analysis.py::TestAnalysisExamples`.

```bash
python tests/analysis_examples/analysis_example_01.py
python -m pytest tests/test_analysis.py::TestAnalysisExamples -v
```

Data lives in `equilibration_folder/` next to these scripts. Paths are relative to this folder.
