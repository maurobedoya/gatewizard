# Security Policy

## Supported versions

Security fixes are provided for the latest release of the GateWizard API on PyPI and GitHub. Older releases are not maintained.

The desktop app is a separate repository, [gatewizard-gui](https://github.com/franciscoadasme/gatewizard-gui). Report vulnerabilities in either project through the contact below.

## Reporting a vulnerability

Report security issues by email to [gatewizard.project@gmail.com](mailto:gatewizard.project@gmail.com).

Please do not open a public GitHub issue for a suspected vulnerability.

Include:

- A short description of the issue and its impact
- The component (API or GUI) and version
- Steps to reproduce, or a proof of concept if you have one
- Your name and whether you want to be credited

We will acknowledge the report, keep the details private while we investigate, and tell you whether we accept it. If we ship a fix, we will credit you unless you ask us not to.
